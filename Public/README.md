# Simulador de Rentabilidad para Emprendedores

Este proyecto es una herramienta educativa para ayudar a emprendedores a validar la rentabilidad de sus negocios mediante indicadores financieros clave.

## Estructura del proyecto

- `index.html`: Archivo principal del frontend.
- `style.css`: Estilos para la aplicación.
- `script.js`: Lógica del frontend.
- `backend.js`: Lógica del backend para cálculos financieros.

## Cómo ejecutar

1. Abre `index.html` en tu navegador para ver el frontend.
2. Usa `backend.js` para cálculos financieros en un entorno Node.js si es necesario.
